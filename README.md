# Calculus Made Easy for Clara

An interactive, intuition-first calculus web application built with **React 18**, **TypeScript**, **Vite**, **Tailwind CSS**, **KaTeX**, and **Lucide React**.

## Core Features
- **5 Complete Curriculum Modules**: Foundations (Pre-Calculus), Limits & Continuity, Differential Calculus (Derivatives), Integral Calculus (Integrals), and Advanced & Multivariable Calculus.
- **Intuition-First Pedagogy**: Every concept opens with a crystal-clear, everyday plain-English sentence before introducing formal notation.
- **Interactive Visual Sandboxes**:
  1. **Derivative & Tangent Line Explorer** (with draggable point & secant-to-tangent slider)
  2. **Riemann Sum Integrator** ($n = 2$ to $n = 100$ with Left, Right, Midpoint, and Trapezoidal rules)
  3. **Taylor & Maclaurin Series Approximator** (watch polynomial approximations wrap around $\sin(x)$, $\cos(x)$, and $e^x$)
  4. **Limit Zoom Microscope & 3D Mountain Gradient Compass**
- **Master Formula Vault & Study Board**: Searchable, filterable calculus cheat sheet with one-click LaTeX copy and pinning to Clara's personal Study Board.
- **Step-by-Step Worked Examples**: Expandable accordions with side-by-side plain-English translations and progressive step reveal.
